# 花園トキネ COEIROINK（111・117・134epoch）

テキスト読み上げソフトウェア「COEIROINK」向けの合成音声モデル（MYCOEIROINK）です。
元の学習方式の111・117・134epoch、3スタイルにアイコン・立ち絵・各3本のサンプル音声を同梱しています。v1.2.0は未補正の原本モデルです。

保存済み133モデルを同じ通常8文で評価した固定周波数・周期性成分の代理指標の上位3件です。総合音質や聴感上の順位ではありません。閾値を変えた順位範囲は111が1〜14位、117が2〜6位、134が3〜95位で、特に134は不安定です。実聴・発音の最終評価は未確認です。

- **スタイル**: 111epoch、117epoch、134epoch
- **音声ライブラリバージョン**: 2.2.0（配布版v1.2.0）

## 導入方法（COEIROINK v2）

旧版を導入済みの場合は、COEIROINKを終了して旧話者フォルダをspeaker_infoの外へ退避してから新版を配置してください。同じ話者UUIDの旧版と新版を同時に配置しないでください。旧100・200epochは今回の配布版に含みません。既存プロジェクトをバックアップし、新しいスタイルを選択してください。モデルの重み・音量補正は行っていないため、従来の音量補正版とは出力レベルが異なります。音量1.00から調整してください。

1. 解凍してできた `hanazono-tokine-2.2.0` フォルダを、COEIROINKの `speaker_info` フォルダ内に配置します。
   - **Windowsの場合**:
     COEIROINK実行ファイルと同じ階層にある `speaker_info` フォルダ内
   - **Macの場合**:
     `COEIROINKv2.app` を右クリック →「パッケージの内容を表示」→ `Contents/MacOS/speaker_info/` フォルダ内
2. COEIROINKを再起動すると「花園トキネ」が使用可能になります。

## 利用規約・クレジット表記

本音声ライブラリを使用して作成した音声を公開・配信される際は、以下のクレジット表記をお願いいたします。

```text
COEIROINK:花園トキネ
```
または
```text
音声：花園トキネ (COEIROINK)
```

詳細な利用規約（商用・非商用利用、禁止事項等）については、同封の `policy.md` を必ずご確認ください。
